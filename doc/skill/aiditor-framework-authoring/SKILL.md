# AIditor Framework Authoring

Use for framework and ordinary AIditor host code. Preserve classic IIFE scripts,
`window.aiditor`, zero runtime dependencies, caller-owned data, and the
Dock/Panel/Component model. Do not place project formats, save semantics,
business workflows, or application shortcuts in Core/UI. Prefer existing UI
primitives and rebuild committed distributions after `src/` changes.
