# AIditor Extension Authoring

An Extension is a package and lifecycle boundary over existing registries, not
a parallel component or AI system. Publish dotted contribution ids and install
all records with exact Owner `extension:<id>`. Disable/uninstall through Owner
cleanup. Keep project business models outside the framework runtime.
